Design and Analysis of Algorithms
This repository contains my Design and Analysis of Algorithms (DAA) practical assignments, implementations, and practice programs completed as part of my college coursework.

The programs in this repository are written in C and include practical assignments completed through my college Moodle, along with additional questions I practiced to strengthen my understanding of algorithms and problem-solving.

📚 Topics Covered
1. Time Complexity of Algorithms
Understanding time and space complexity
Best, average, and worst-case analysis
Big O, Big Omega, and Big Theta notation
Analyzing the efficiency of algorithms
Comparing different approaches to the same problem
2. Divide and Conquer
Learned how to design and implement algorithms using the Divide and Conquer technique.

Key concepts:

Dividing a problem into smaller subproblems
Solving subproblems recursively
Combining the results
Analyzing recursive algorithms
3. Greedy Technique
Learned how to design and implement algorithms using the Greedy approach.

Key concepts:

Making locally optimal choices
Applying greedy strategies to optimization problems
Understanding when the greedy approach can produce an optimal solution
Analyzing the efficiency of greedy algorithms
4. Dynamic Programming
Learned how to solve problems using Dynamic Programming (DP).

Key concepts:

Overlapping subproblems
Optimal substructure
Memoization
Tabulation
Improving the efficiency of recursive solutions
5. Competitive Programming – Certain Techniques
Practiced different problem-solving techniques used in competitive programming.

This helped me improve my ability to:

Analyze problems efficiently
Develop optimized solutions
Reduce time complexity
Apply appropriate algorithmic techniques
Solve programming problems systematically
